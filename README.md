## 🚀 Free Hosting & Live Deployment (GitHub Pages & Vercel)

This project is built and optimized with static export support for **both GitHub Pages and Vercel**:

### 1. Host on GitHub Pages (Automated via GitHub Actions)
Anyone can view your portfolio directly at:
**`https://anusah99.github.io/DevOPs_Pro/`**

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: DevOPs_Pro portfolio with 6 interactive projects and admin cms"
   git branch -M main
   git remote add origin https://github.com/AnuSah99/DevOPs_Pro.git
   git push -u origin main
   ```
2. In your GitHub repository **Settings**:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. The included workflow `.github/workflows/deploy.yml` will automatically build and publish your portfolio to GitHub Pages on every push to `main`!

---

### 2. Host on Vercel (Instant Zero-Config)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New...** -> **Project**.
3. Select the `DevOPs_Pro` repository.
4. Click **Deploy**.
5. Your portfolio goes live worldwide on `devops-pro.vercel.app` in under 60 seconds!
